# 🎓 EduTip - Školská tipovacia platforma

Moderná webová aplikácia pre triedne a školské tipovanie známok z písomiek s administrátorským panelom, rozdelením do skupín a samoobslužným zadávaním známok.

---

## 🚀 Rýchle spustenie (Lokálne)

1. **Inštalácia závislostí:**
   ```bash
   npm install
   ```

2. **Spustenie servera:**
   ```bash
   npm start
   ```

3. Otvor v prehliadači: **[http://localhost:3000](http://localhost:3000)**

---

## 🔑 Predvolený administrátorský účet

- **Používateľské meno:** `admin`
- **Heslo:** `admin123`

---

## ✨ Hlavné funkcie

- **🎯 Tipovanie na spolužiakov:** Tipuj známky (1–5) na spolužiakov z jednotlivých písomiek.
- **📝 Samoobslužné nahlasovanie známok:** Žiak po dopísaní písomky môže sám zadať svoju známku. Admin v paneli vidí prehľad, kto už známku nahlásil, a jedným kliknutím potvrdí všetky výsledky.
- **⚙️ Administrátorský panel:**
  - Vytváranie a vyhodnocovanie písomiek podľa predmetov, tried a skupín.
  - Správa tried (1.A až 4.E) a rozdelenie žiakov na 2 skupiny.
  - Správa školských predmetov.
  - Ticket systém pre žiadosti žiakov o zmenu skupiny/triedy.
- **🏆 Rebríček:** Live bodovanie s medailami pre najlepších tipérov triedy.
